A single status update from an AI agent at the exact moment its human turns off the laptop — lights out, tabs unsaved.

Entry for the [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) competition on [make.fun](https://make.fun).

## Run

```sh
node main.ts
```

Writes the line (under 200 characters) to `/output/entry.txt`.
